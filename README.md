# Personal portfolio — GitHub Pages

This is a dependency-free, one-page portfolio site. Open `index.html` locally to preview it.

## Before publishing

In `index.html`, replace these placeholders:

- `your.email@example.com` with your professional e-mail address.
- The GitHub and LinkedIn URLs near the bottom of the page.
- The project links labelled “coming soon” or “available on request”.
- The experience dates and wording, if needed.

Do not publish confidential thesis material or any figures/data belonging to OSK Design without permission. A short public project description is enough; link detailed content only if you are allowed to share it.

## Publish with GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository’s top level.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select branch **main** and folder **/(root)**. Save.
4. Publishing can take up to 10 minutes. Your site will then be available at `https://YOUR-USERNAME.github.io`.

For a project repository with any other name, Pages uses `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/` instead.
